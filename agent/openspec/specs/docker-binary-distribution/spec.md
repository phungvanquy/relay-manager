## ADDED Requirements

### Requirement: Docker image bundles all platform binaries
The Docker image SHALL include agent binaries for all supported platforms in `/app/releases/`.

#### Scenario: All platform binaries present in image
- **WHEN** the Docker image is built after running the full build
- **THEN** the `/app/releases/` directory contains binaries for linux (amd64, arm64, arm, mips, mipsle, mips64, mips64le), freebsd (amd64, arm64), and darwin (amd64, arm64)

### Requirement: Releases API serves all platform binaries
The releases API SHALL serve any agent binary that exists in the releases directory and matches the expected naming pattern.

#### Scenario: Download a valid platform binary
- **WHEN** a client requests `/api/releases/relay-agent-linux-mips`
- **THEN** the API returns the binary file with `application/octet-stream` content type

#### Scenario: Reject invalid filename
- **WHEN** a client requests `/api/releases/../../etc/passwd`
- **THEN** the API returns a 404 error

#### Scenario: Reject non-existent platform
- **WHEN** a client requests `/api/releases/relay-agent-windows-amd64` and no such file exists
- **THEN** the API returns a 404 error

### Requirement: Bootstrap script detects all supported architectures
The bootstrap script generated by the bootstrap API SHALL detect and map all supported OS/architecture combinations.

#### Scenario: MIPS architecture detection
- **WHEN** the bootstrap script runs on a Linux MIPS system (`uname -m` returns "mips")
- **THEN** it downloads `relay-agent-linux-mips`

#### Scenario: ARM architecture detection
- **WHEN** the bootstrap script runs on a Linux ARM system (`uname -m` returns "armv7l")
- **THEN** it downloads `relay-agent-linux-arm`

#### Scenario: FreeBSD detection
- **WHEN** the bootstrap script runs on a FreeBSD amd64 system
- **THEN** it downloads `relay-agent-freebsd-amd64`

#### Scenario: Unsupported platform error
- **WHEN** the bootstrap script runs on an unsupported platform
- **THEN** it exits with an error listing supported platforms

### Requirement: Root Makefile orchestrates full build
A Makefile at the project root SHALL provide targets to build agent binaries and the Docker image in sequence.

#### Scenario: Build everything
- **WHEN** the user runs `make all` from the project root
- **THEN** all agent binaries are built, copied to `releases/`, and the Docker image is built with them included

#### Scenario: Build agent only
- **WHEN** the user runs `make agent` from the project root
- **THEN** all agent binaries are built and copied to `releases/` without building the Docker image

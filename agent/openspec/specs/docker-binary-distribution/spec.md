## ADDED Requirements

### Requirement: Docker image bundles supported agent binaries

The Docker image SHALL include Linux AMD64 and ARM64 agent binaries and checksum files in `/app/releases/`.

#### Scenario: All platform binaries present in image

- **WHEN** the Docker image is built after running the full build
- **THEN** `/app/releases/` contains `relay-agent-linux-amd64`, `relay-agent-linux-arm64`, and their `.sha256` files

### Requirement: Releases API serves supported binaries and checksums

The releases API SHALL serve any supported agent binary or `.sha256` file that exists in the releases directory and matches the expected naming pattern.

#### Scenario: Download a valid platform binary

- **WHEN** a client requests `/api/releases/relay-agent-linux-arm64`
- **THEN** the API returns the binary file with `application/octet-stream` content type

#### Scenario: Download a checksum

- **WHEN** a client requests `/api/releases/relay-agent-linux-arm64.sha256`
- **THEN** the API returns the checksum with `text/plain` content type

#### Scenario: Reject invalid filename

- **WHEN** a client requests `/api/releases/../../etc/passwd`
- **THEN** the API returns a 404 error

#### Scenario: Reject non-existent platform

- **WHEN** a client requests `/api/releases/relay-agent-windows-amd64` and no such file exists
- **THEN** the API returns a 404 error

### Requirement: Bootstrap script detects supported architectures

The bootstrap script generated by the bootstrap API SHALL detect Linux AMD64 and ARM64 and reject every other platform.

#### Scenario: AMD64 architecture detection

- **WHEN** the bootstrap script runs on Linux x86_64
- **THEN** it downloads and verifies `relay-agent-linux-amd64`

#### Scenario: ARM64 architecture detection

- **WHEN** the bootstrap script runs on Linux aarch64
- **THEN** it downloads and verifies `relay-agent-linux-arm64`

#### Scenario: Unsupported platform error

- **WHEN** the bootstrap script runs on an unsupported platform
- **THEN** it exits with an error listing Linux AMD64 and ARM64 as supported

### Requirement: Root Makefile orchestrates full build

A Makefile at the project root SHALL provide targets to build agent binaries and the Docker image in sequence.

#### Scenario: Build everything

- **WHEN** the user runs `make all` from the project root
- **THEN** all agent binaries are built, copied to `releases/`, and the Docker image is built with them included

#### Scenario: Build agent only

- **WHEN** the user runs `make agent` from the project root
- **THEN** all agent binaries are built and copied to `releases/` without building the Docker image
